A Multi-Agent RAG system for Craster HR policies
that answers employee questions accurately
with verified citations and page numbers
built to production standards


LANGUAGE        Python 3.11

FRAMEWORK       LangChain 0.3.7    document loading
                                   text splitting
                                   prompt templates
                                   retrieval chains


ORCHESTRATION   LangGraph 0.2.28   multi agent pipeline
                                   state machine
                                   conditional routing


LLM             Claude Sonnet      answer generation
                                   routing decisions
                                   context evaluation

EMBEDDINGS      BAAI/bge-base      free local model
                en-v1.5            768 dimensions
                                   no API cost


VECTOR DB       Supabase           pgvector extension
                                   persistent storage
                                   scales to millions


MONITORING      Langfuse           every query logged
                MLflow             experiment tracking


API             FastAPI            production grade
                                   async endpoints

FRONTEND        React              chat interface
                                   built as artifact


CONTAINERISE    Docker             consistent environment
CI/CD           GitHub Actions     automated testing
                                   automated deployment
